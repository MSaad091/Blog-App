# ✍️ MERN Blog Application

A full-stack blog application built using the **MERN Stack (MongoDB, Express.js, React.js, Node.js)**.  
This platform allows users to create, update, and interact with blogs, including commenting and liking posts, providing a complete social blogging experience.

---

## 🚀 Live Demo

- 🌐 Blog App: https://blog-app-znpr.vercel.app  

---

## ✨ Features

### 👤 User Features
- User Registration & Login (JWT Authentication)
- Secure Logout System
- Create Blog Posts
- Update Own Blog Posts
- View All Blogs
- Like / Unlike Blog Posts
- Comment on Blogs
- Delete Own Comments
- View Other Users' Blogs
